Flux Studio relie un générateur simple, un éditeur de workflows visuel et votre installation ComfyUI. Les modèles et les calculs restent sur votre machine. C’est aussi un terrain d’expérimentation pour l’IA appliquée au soutien informatique et les intégrations fiables entre outils.

De l’idée à l’image, sans perdre le contrôle.

Génération simple

Choisissez un modèle, écrivez vos prompts, réglez dimensions, steps, CFG, seed et LoRA, puis envoyez le workflow à ComfyUI.

Workflows visuels

Assemblez les nœuds, reliez les sorties, partez de modèles prêts à l’emploi et vérifiez les workflows avant de les exécuter.

Premiers pas

Mettre en route Flux Studio en quatre étapes.

Installer ComfyUI et PythonFlux Studio utilise l’API ComfyUI et les modèles déjà installés sur la machine de calcul.
Configurer les cheminsCopiez .env.example en .env, puis adaptez COMFYUI_ROOT et les options locales.
Démarrer ComfyUI puis Flux StudioLaissez ComfyUI écouter sur localhost:8188, puis démarrez le serveur Flux Studio sur localhost:8080.
Générer ou ouvrir WorkflowCommencez en mode App ou sélectionnez un workflow nodal prêt à l’emploi et lancez-le.
Suivre l’installation détaillée

À propos de l’hébergement

GitHub Pages publie ce guide statique; il ne fait pas tourner Python, ComfyUI, SQLite ou les modèles. Le backend doit tourner sur un serveur privé équipé/configuré pour ComfyUI. Flux Studio est conçu pour un usage local, sans authentification intégrée : ne publiez pas son API directement sur Internet.
